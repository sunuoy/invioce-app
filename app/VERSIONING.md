# Versioning Rules

When modifying this application, please follow these versioning rules:

- **Small Changes / Bug Fixes / Minor Tweaks**: Increment the patch version (e.g., `v0.0.1`, e.g., `1.8.0` ➔ `1.8.1`).
- **Medium Changes / New Features / UI Enhancements**: Increment the minor version (e.g., `v0.1.0`, e.g., `1.8.0` ➔ `1.9.0`).
- **Major Changes / Complete Redesign / Breaking Core Features**: Increment the major version (e.g., `v1.0.0`, e.g., `1.8.0` ➔ `2.0.0`).
