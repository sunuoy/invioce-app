# Release v1.19.9

## Changelog (v1.19.8 to v1.19.9)

### 💳 Payment & Closure Details
- **Payment Method Confirmation**: When marking an invoice as **Paid** (via detail sheets or invoice editor), you can specify payment method (Cash, UPI, Cheque), add transaction/cheque reference notes, and attach receipt screenshot images which are copied locally to the app's persistent storage.
- **Closure Reason Details**: When marking an invoice as **Closed**, the app prompts you for a description/reason for closing (e.g. Order Cancelled, Product Returned, Bad Debt).
- **Detail Displays**: Stylized visual cards showing payment modes/references or closing reason text are dynamically rendered inside the invoice details card stack.

### 🔒 Client Directory Safeguards
- **Client Deletion Protection**: Active clients with generated invoices cannot be hard deleted. If attempted, they can be marked as **Closed** (marked visually with a red badge).
- **Dropdown Exclusion**: Inactive/closed clients are automatically filtered out from recipient selection lists when generating new invoices.
- **Clients Directory CSV Sync**: Customer CSV import and export templates have been expanded to include the **`Closed`** boolean column status.
